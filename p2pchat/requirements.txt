# Runtime + test dependencies for CI and local development.
#
# This is the file CI installs (`pip install -r p2pchat/requirements.txt
# -r p2pchat/platform/build-requirements.txt -c p2pchat/platform/constraints.txt`)
# and the only file that decides what the shipped Python code may import.
# `p2pchat/requirements-lock.txt` is the *record* of the exact versions that were
# tested (used for the frozen environment, see docs/DESKTOP-PYTHON.md); the two
# must never disagree about which packages exist.
#
# `p2pchat/tests/desktop/test_declared_dependencies.py` fails if the product code
# imports a third-party module that is not declared here, so adding an import
# without adding it to this file breaks CI on purpose.
